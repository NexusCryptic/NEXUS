# Living System Runtime

Public historical archive and runtime convergence record for the NEXUS Living System.

## Purpose

This directory preserves the evolution of the current runtime architecture: memory, event mesh, Cartographer, Dream Engine, reflection, visualization, persistence, and provider orchestration.

The archive is intentionally additive. Historical material is preserved as provenance rather than silently rewritten into a single canonical implementation.

## Public-history policy

- Preserve chronology and provenance.
- Do not publish credentials, tokens, private keys, or other secrets.
- Do not publish private addresses or other unnecessary personal data.
- Keep experimental designs distinguishable from production code.
- Prefer append-only history over destructive rewriting.

## Current focus

The Living System Runtime is the active convergence surface for the current chat-driven development process. Earlier Nexus, GAIA, Chronosphere, Dream Engine, Cartographer, Planetarium, OmniKernel, and memory-fabric work is treated as historical input to this runtime.
