# NEXUS V2 Kernel — Unified Space-Time Runtime Fabric

This release merges the project's browser-native runtime concepts with the uploaded unified space-time mathematical engine and the documented AI/memory/telemetry architecture.

## Components

- WebGL/GLSL implicit-field viewport
- direct exponential/logarithmic controls
- Clifford-inspired rotor with quaternion fallback
- Riemannian metric warp
- SDF ray marching
- multiresolution hash-grid neural-implicit approximation
- simulated subgroup/wave-level controls
- process manager
- IndexedDB filesystem facade
- BFCache-aware state restore and soft revalidation
- BroadcastChannel mesh synchronization
- deterministic snapshot hashing
- AI Core adapter boundary for authorized local/cloud model gateways
- telemetry and trajectory drift monitor
- provenance ledger

## Security boundary

The browser UI never contains provider API secrets. AI integration is an adapter boundary: credentials remain in an authorized backend/local gateway. BFCache snapshots are treated as UI state, not authentication or authorization evidence.

## Research status

The engine is a first-party experimental synthesis of the project's uploaded artifacts. Claims such as "world's first" are retained as project provenance language, not independently established priority claims.
