# NEXUS

Public project surface for the Living System / GAIA / NEXUS architecture.

## Canonical architecture

```text
NEXUS Protocol
      ↓
NEXUS Core / OmniKernel⁹
      ↓
Memory + Ledger + Event Mesh
      ↓
Cartographer + Dream Engine + AI Gateway
      ↓
Planetarium / Runtime / Public NEXUS
```

The public repository is a presentation and integration surface. Normative contracts belong in [`NEXUS_Protocol`](https://github.com/NexusCryptic/NEXUS_Protocol); provenance belongs in [`The-Ledger`](https://github.com/NexusCryptic/The-Ledger).

## Review principles

- Preserve repository and artifact lineage.
- Separate canonical project work from external research and forks.
- Keep credentials and secrets outside source control.
- Prefer protocol-defined modules over ad hoc integrations.
- Record significant changes in the ledger.
- Require human review before release or privileged execution.
